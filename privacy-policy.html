Overview

The short version: This site is a free, static installation guide. It doesn't have accounts, forms, or logins. The only data collected is standard, anonymized website analytics (via Google Analytics) to see how many people visit and which pages are useful.

This policy explains what information the DVWA Setup Guide website (this site) collects when you visit, and how that information is used.

Data We Collect

This site does not ask you to create an account, sign up, or submit any personal information. The only data collected is automatic, aggregated usage data via Google Analytics, including:

  • Pages visited and time spent on each page
  • Approximate location (country/city, derived from IP address)
  • Device, browser, and operating system type
  • Referring website or search query that brought you here

This data is aggregated and anonymized by Google Analytics — we do not see your name, email address, or any other directly identifying information.

Cookies

This site does not set any cookies of its own. Google Analytics sets a small number of first-party cookies (such as _ga) to distinguish unique visitors and sessions. These cookies don't identify you personally and aren't used for advertising.

How This Information Is Used

We use analytics data only to:

  • Understand how many people use the guide and where they run into trouble
  • Decide which sections need more detail (e.g. the Troubleshooting page)
  • See which search terms bring people here, to keep the guide relevant

We do not sell, rent, or share this data with third parties beyond Google Analytics itself, and this site does not run ads.

Third-Party Services

This site relies on a couple of third-party services:

  • Google Analytics — collects the usage data described above. See Google's Privacy Policy.
  • GitHub Pages — hosts this site. GitHub may log standard server data (like IP address) as part of serving the page. See GitHub's Privacy Statement.

This site also links out to external resources (GitHub, OWASP, Ubuntu, Kali Linux, Apache, MySQL, PHP, and similar). Those sites have their own privacy policies, and this policy doesn't cover them.

Your Choices

  • Block or clear cookies anytime in your browser settings.
  • Install the Google Analytics Opt-out Browser Add-on to stop Analytics tracking on any site, including this one.
  • Use a browser extension or setting that blocks tracking scripts — the guide's instructions and commands work exactly the same either way.

Children's Privacy

This site is intended for general audiences interested in web security education and is not directed at children under 13. We do not knowingly collect personal information from children.

Changes to This Policy

If this policy changes, the update will be posted on this page with a revised "Last updated" date above. Continued use of the site after a change means you accept the updated policy.

Contact

Questions about this policy? Open an issue on the GitHub repository.
